
Electrum-VRSC — Lightweight Wallet for Verus Coin
=================================================

**Electrum-VRSC** is a desktop wallet tailored for users of the Verus Coin (VRSC) blockchain. It provides non-custodial control of funds, secure backup via seed phrases, and the speed of SPV (Simplified Payment Verification) — all while maintaining cross-platform compatibility.

* * *

Features
--------

* Lightweight and fast — no full blockchain download required
    
* Non-custodial — you control your private keys
    
* Windows-platform — works on Windows
    
* Backup and recovery with 12-word seed phrase
    
* Compatible with most hardware wallets
